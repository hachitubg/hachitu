# Role artwork

Generated using the built-in imagegen tool for HACHITU, then resized and encoded as WebP. Final assets follow the repository image optimization pipeline (quality 80): `roles.webp`: 1200 x 1200; `basic-extra.webp`: 1500 x 1200; `expansion.webp`: 1920 x 960. The UI uses inset CSS sprite sampling to avoid neighboring panels bleeding at tile edges. All 67 character roles have distinct portraits across the three atlases. Utility cards are excluded from the library.
