# Studio fonts

Self-hosted, unmodified TrueType fonts downloaded 2026-10-28 from the official
Google Fonts repository: https://github.com/google/fonts

- `lora.ttf`: `ofl/lora/Lora[wght].ttf`
- `roboto-mono.ttf`: `ofl/robotomono/RobotoMono[wght].ttf`
- `dancing-script.ttf`: `ofl/dancingscript/DancingScript[wght].ttf`
- `barlow-condensed.ttf`: `ofl/barlowcondensed/BarlowCondensed-Bold.ttf`

Each family retains its own `*-OFL.txt` license alongside the font. Fonts are
loaded by the browser from this website only; no photo or text is sent to a
third-party font service. Be Vietnam Pro and Anybody remain site-wide fonts.
